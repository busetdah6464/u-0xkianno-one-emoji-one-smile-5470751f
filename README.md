# One Emoji, One Smile

Entry for the make.fun bounty
[u-0xkianno-one-emoji-one-smile-5470751f](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f):
send exactly one emoji, the one most likely to make a stranger smile.

## The entry

🌻 — a sunflower.

A sunflower reads as warm like sunshine, friendly without intimacy,
and instantly readable by a stranger of any age or background. It is a
deliberate pick — not the default smiley face — and carries no irony,
in-joke, sarcasm, or flirtation that could land wrong from someone
unknown.

## How it works

`main.py` (Python standard library only) writes exactly that one emoji,
with no trailing newline and no other text, to `/output/entry.txt`.
The program is deterministic: every run produces byte-identical output.

Verified locally: the output file holds exactly 1 character (the single
emoji), valid UTF-8, and passes the kit's gate of 1–8 characters.
